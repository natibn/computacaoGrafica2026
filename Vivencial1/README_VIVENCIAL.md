## Controles

- **TAB** — Selecionar próximo objeto
- **1, 2, 3** — Selecionar objeto direto
- **W/S** — Mover objeto selecionado para frente/trás
- **A/D** — Mover objeto selecionado para esquerda/direita
- **Q/E** — Mover objeto selecionado para cima/baixo
- **K/L** — Diminuir/Aumentar escala do objeto selecionado
- **X/Y/Z** — Selecionar eixo de rotação
- **R/T** — Girar objeto selecionado (+/-15 graus no eixo)
- **ESC** — Sair
